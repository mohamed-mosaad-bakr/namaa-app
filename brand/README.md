# لوجو نماء: نقطة النون

**الفكرة:** حرف «ن»، أول حرف في «نماء»، ونقطته بقت نبتة. نفس النبتة دي هي نقطة النون جوه كلمة «نماء».

## الملفات
| الملف | الاستخدام |
|---|---|
| `namaa-symbol.svg` | الرمز الأساسي، من 48px وأكبر |
| `namaa-symbol-small.svg` | نسخة أتقل للمقاسات الصغيرة: الـ favicon وأيقونة الموبايل، وأي مقاس أقل من 48px |
| `namaa-horizontal-ar.svg` | الرمز على اليمين، و«نماء» على الشمال |
| `namaa-horizontal-en.svg` | الرمز على الشمال، و«Namaa» على اليمين |
| `namaa-bilingual.svg` | الرمز مع «نماء» وتحتها «Namaa» |
| `namaa-wordmark-ar.svg` | كلمة «نماء» لوحدها، ونقطة النون فيها نبتة |
| `lockups/` | نسخ أسود وأبيض وأخضر بس + PNG بعرض 1200 |
| `web/` | الـ favicon وأيقونات الـ PWA والـ manifest |
| `app-icons/` | أيقونة لكل ثيم من الـ 19 (SVG + PNG 512) للـ APK الجاي |
| `board.html` / `board.png` | لوحة العرض بالـ mockups |

## الألوان
- **الحرف:** `#1E6B45`.
- **النبتة:** `#2E9E52`، وتباينها مع الأبيض 3.3:1.
- **على الخلفية الغامقة:** الحرف `#F5EFE5`، والنبتة `#A8D58A`.
- **لون واحد:** كله `#1E6B45`، أو كله أسود، أو كله أبيض.

## قواعد الاستخدام
- **المسافة الفاضية حوالين اللوجو:** على الأقل قد عرض ورقة واحدة من النبتة، من كل ناحية.
- **أقل مقاس للرمز:** 16px بالنسخة الصغيرة. **أقل مقاس للوجو بالكلمة:** 24px في الطول.
- **ممنوع:** تمطّه، أو تلفّه، أو تغيّر ألوانه برا الثيمات، أو تحط له ظل أو تدرّج لون.
- **الخط:** Readex Pro Bold (رخصة OFL، مسموح يتستخدم في لوجو). اتحوّل لأشكال، فمش محتاج الخط يتسطّب.

## أيقونات الثيمات (للـ APK الجاي)
- **الثيمات الفاتحة:** خلفية الأيقونة اللون الفاقع، والحرف بلون الكلام.
- **الثيمات الغامقة:** خلفية الأيقونة هي خلفية الثيم، والحرف فاتح، والنبتة اللون الفاقع.
- **ثيمات اللون الواحد:** خلفية الأيقونة لون الثيم، والحرف كريمي.

## ملاحظة
مفيش بحث اتعمل عن العلامة التجارية. لازم بحث متخصص قبل ما اللوجو يتسجّل.
